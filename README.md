# Bash Scripts

Репозиторий служебных bash-скриптов.

## Структура

```bash
common/
├─ all/            # скрипты, работающие на всех окружениях
├─ dev/            # скрипты для dev
├─ prod/
│  ├─ all/         # скрипты для всех prod-площадок
│  ├─ com/         # только prod com
│  └─ ru/          # только prod ru
├─ inProgress/     # скрипты в разработке
└─ notUse/         # неиспользуемые / архивные
```

## Правила размещения

* работает везде → `common/all/`
* только dev → `common/dev/`
* только prod → `common/prod/...`
* только конкретная площадка → `common/prod/com` или `common/prod/ru`
* в разработке → `common/inProgress/`
* не используется → `common/notUse/`

Если скрипт работает и в `prod`, и в `dev`, его нужно класть в `common/all/`.

## Запуск

Скрипты лежат в `~/.local/bin` и запускаются как обычные команды, если директория добавлена в `$PATH`.

Примеры:

```bash
getError.sh
deploy.sh
cleanDb.sh
```

## Header в скриптах

Рекомендуемый минимальный header:

```bash
#!/usr/bin/env bash
# purpose: что делает скрипт
# env: all | dev | prod
# usage: как запускать
# note: необязательно
```

Пример:

```bash
#!/usr/bin/env bash
# purpose: получение ошибок сервиса
# env: all
# usage: getError.sh
```

## Важно

* не хранить секреты в репозитории
* не дублировать один и тот же скрипт в нескольких папках
* если скрипт подходит для нескольких окружений, класть его выше по иерархии
